## 1. Факты о компании

До production подтвердить и при необходимости внести в сайт:

- полное юридическое имя владельца/издателя сайта;
- регистрационный статус и номер в применимом реестре автоперевозчиков;
- страховую компанию, номер договора, виды деятельности и географию покрытия;
- выбранного médiateur de la consommation;
- реальные способы оплаты;
- часы связи и реальный срок ответа на заявку;
- наличие и характеристики автомобилей и оборудования;
- доступность monte-meubles, garde-meuble и международных перевозок;
- актуальность всех опубликованных ориентиров цен.

Пока подтверждений нет, на сайте не должны появляться слова «assuré», точные
SLA, история без повреждений, собственный склад, собственный международный парк
или условия скидок/отмены.

## 3. Аналитика

- в GA4 проверить, включён ли Enhanced Measurement для форм;
- не считать одновременно автоматический `form_submit` и ручной
  `form_submit` сайта одной конверсией;
- основная конверсия мастера: `devis_wizard_submit`;
- дополнительные события: шаги, просмотр оценки, звонок, WhatsApp,
  калькулятор объёма, калькулятор коробок и checklist;
- проверить UTM, `lead_source`, landing page и referrer тестовой заявкой;
- не включать Google Analytics без согласия cookie banner.

Для безопасного агрегированного отчёта из CSV:

```bash
npm run report:leads -- chemin/vers/export.csv
npm run report:leads -- chemin/vers/export.csv --output rapport.md
```

Скрипт не выводит имена, телефоны, email, адреса, сообщения и фотографии.

## 5. Первый реальный кейс

Для публикации нужны:

- маршрут только на уровне городов, без точного частного адреса;
- тип проекта, объём, продолжительность и состав команды;
- реально выполненные услуги;
- фактические сложности и решения;
- оригинальные фотографии с размерами и alt-текстом;
- письменное разрешение клиента на текст;

- при наличии отзыва — точная цитата и ссылка на источник.

Данные добавляются в `src/data/realisations.ts`. После первого опубликованного
кейса нужно убрать исключение `/realisations` из sitemap в `astro.config.mjs`:
сейчас пустой раздел честно закрыт от индексации.
